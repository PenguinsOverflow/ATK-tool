# ATK-tool

CLI tool for attacks and penetration testing. 

## 📦 Requirements
- C++20
- CMake 3.20+

## 🚀 Build
```bash
git clone https://github.com/PenguinsOverflow/ATK-tool
cd ATK-tool
mkdir build
cmake -S . -B build
cd build
cmake --build .
sudo cmake --install .
atk -h
```
